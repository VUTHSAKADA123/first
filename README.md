# My Portfolio

A professional portfolio website built with HTML, CSS, and JavaScript.

## Project Structure

```
├── index.html           # Main HTML file
├── css/
│   └── styles.css      # Stylesheet
├── js/
│   └── script.js       # JavaScript functionality
├── assets/
│   ├── images/         # Image files
│   └── fonts/          # Custom fonts
└── README.md           # Project documentation
```

## Files Description

- **index.html** - Main HTML file containing the portfolio content
- **css/styles.css** - All styling and responsive design rules
- **js/script.js** - Interactive features and functionality
- **assets/** - Directory for images, fonts, and other media files

## Getting Started

1. Open `index.html` in your web browser
2. Customize the content with your information
3. Update styles in `css/styles.css` as needed
4. Add interactive features in `js/script.js`

## Features

- Responsive design for mobile and desktop
- Clean, professional layout
- Easy to customize and extend
- Semantic HTML structure

## Tips

- Keep images optimized for web in `assets/images/`
- Use `assets/fonts/` for custom fonts
- All CSS is centralized in `styles.css` for easy maintenance
- JavaScript functionality is separated for better organization
